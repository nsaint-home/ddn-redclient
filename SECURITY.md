# Security Policy

## Supported versions

Security fixes are published for the latest release of DDN-RedClient. Upgrade to the newest package from this repository’s Releases page when a fix is available.

## Reporting a vulnerability

Please report security issues privately. Do not open a public GitHub issue for vulnerabilities.

Contact the maintainer:

- Norman St.Pierre — nstpierre@ddn.com
- Norman St.Pierre — norman.stpierre@gmail.com

Include:

- The RedClient version (`redclient --version` or `redc --version`)
- OS and install type (`.deb`, `.rpm`, or zip)
- A clear description of the issue and steps to reproduce, if possible

You should receive an acknowledgement when the report is received. After a fix is released, details may be summarized in the Release notes and [CHANGELOG.md](CHANGELOG.md).
